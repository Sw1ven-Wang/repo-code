# Verify a Python change

Read the current implementation before editing. Use the repository's existing test command and environment. When execution fails, read the error and obtain new evidence before repeating a deterministic failed command. Distinguish source checks from built-artifact checks. Do not claim success until the Host contract has actually passed.

This is a manually reviewed example, not a measured automatically evolved skill. It cannot grant permissions, change acceptance, or bypass budgets.
